# Ukraine & Russia ACLED Conflict Dashboard

A self-contained conflict-monitoring dashboard built from real ACLED (Armed Conflict Location & Event Data) records covering Ukraine and Russia, 2022-01-01 to 2026-08-07 (351,530 events, 275,662 fatalities).

**Live site:** https://matts-maps.github.io/acled-ukraine-russia-dashboard/

## Pages

- **Overview** (`index.html`) — KPIs, map (locations + heat map view), event-type/actor charts, incident table. Click a map marker, chart bar, or table row to cross-filter the whole page.
- **Trend Analysis** (`ukraine_russia_acled_trend_analysis.html`) — cumulative/year-over-year trends, lethality by event type.
- **Raion Drill-down** (`ukraine_russia_acled_raion_subnational.html`) — sub-national detail: Ukraine by oblast → raion, Russia by Federal District → oblast/republic/krai-equivalent.

## Data

Source data is ACLED's own CSV export (not included in this repo — see the [2026-epacc-ukraine-russia project](../../..) for the generator config and ingestion notes). Every chart, the map, and the table share one filter state.

## How this is built

Generated by a shared Python dashboard generator (also used for MapAction's Yemen and Middle East ACLED dashboards) from a per-region JSON config, a boundary GeoJSON, and an ACLED CSV export. Each page is a single self-contained HTML file — no build step or server needed to view it, just open it in a browser or visit the GitHub Pages URL above.
